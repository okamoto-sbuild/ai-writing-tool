# AIライティングツール

Python + Streamlit + Gemini API で作った、個人用の文章作成ツールです。データベース・ログインはありません。

## 使えるツール

| ツール | できること |
|---|---|
| 📝 ブログ記事 | テーマ・キーワードから見出しつきの記事（＋メタディスクリプション） |
| ✉️ メール返信 | 受信メールを貼ると返信案（件名つき・最大3案） |
| 📋 要約 | 箇条書き／3行／要点＋アクションなど形式を選んで要約 |
| ✏️ 校正・リライト | 誤字脱字チェック（修正箇所一覧つき）、丁寧に・簡潔に など |
| 🌐 翻訳 | 8言語、文体指定、訳注つきも可 |
| 📣 SNS投稿 | X / Instagram / Facebook / LinkedIn / Threads の作法に合わせた投稿案 |
| 💡 タイトル・キャッチコピー | 記事タイトル・件名・コピーを切り口を変えて多数 |
| 🗂️ 議事録・メモ整形 | 走り書きを議事録・ノート・ToDo に |
| 🧠 アイデア出し | お題に対してアイデアを列挙 |
| 💬 自由入力 | 何でも |

共通機能：ストリーミング表示／結果への追加修正指示／コピー・Markdown 保存／セッション内の履歴／モデルと創造性（temperature）の切り替え

## 起動

```
pip install -r requirements.txt
streamlit run app.py
```

（Windows なら `起動.bat` のダブルクリックでも可）

API キーは `.env`（`.env.example` をコピー）の `WRITING_TOOL_API_KEY` に書きます。このアプリ専用の変数で、いちばん先に読まれます。無い場合は環境変数 `GEMINI_API_KEY` → `GOOGLE_API_KEY` の順に探し、どれも無ければ画面のサイドバーで入力できます。サイドバーには、どの変数から読んだかが表示されます。

## ツールを追加するには

`tools.py` に、プロンプトを組み立てる関数と `Tool(...)` を1つ足して `TOOLS` に並べるだけです。入力欄は `fields` から自動で作られます。
